[assistant] Excalidraw uses **two stacked `<canvas>` layers**, driven from React but rendered imperatively.

**Rendering**
- `StaticCanvas` (elements/grid/background) and `InteractiveCanvas` (selection, handles, cursors) overlay each other.
- Each is a `React.memo` component; its `useEffect` calls an imperative renderer — `renderStaticScene` / `renderInteractiveScene` — on every commit. React only manages the DOM node; pixels are drawn manually.
- `renderStaticScene` (`renderer/staticScene.ts`) sets up the context via `bootstrapCanvas`, applies `zoom`/scroll, draws the grid, then iterates `visibleElements` calling `renderElement` (`packages/element/src/renderElement.ts`) per element. Non-iframe elements first, embeddables + bound text on top, with per-frame clipping. Shapes come from RoughJS (`rc`) via cached `generateElementShape`.

**Updating**
- `areEqual` gates re-render: it re-renders only when `canvasNonce`, `scale`, `elementsMap`, `visibleElements`, or relevant `appState` props change (`isShallowEqual`). So element edits bump a nonce / produce a new elements map, triggering a repaint.
- Draws are throttled to the frame rate via `renderStaticSceneThrottled` (`throttleRAF`) when `isRenderThrottlingEnabled()` — one paint per animation frame regardless of how many state updates fired.
- Element shapes are cached and regenerated only when an element's version changes; the whole scene is cleared and redrawn each paint (immediate-mode), not diffed.
